# Careera — Job Portal

Careera is a modern job portal web application designed to connect job seekers with career opportunities through a clean, responsive, and user-focused interface.

## ✦ About

Careera provides a polished job-search experience where users can explore opportunities, view job details, and navigate through different career-focused sections.

The project was built to demonstrate modern frontend development using Vue 3, Vue Router, and SCSS, with a structure prepared for future backend and database integration.

## 🛠️ Technologies

* Vue 3
* JavaScript
* Vue Router
* SCSS
* HTML5
* CSS3
* Vue CLI

## ✨ Features

* Responsive job portal interface
* Job listings
* Job detail views
* Category-based navigation
* Client-side routing
* Modern responsive layout
* Clean and accessible UI
* Reusable Vue components and views
* Mobile-friendly design

## 🚀 Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
```

Open the project folder:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run serve
```

The application will be available at:

```text
http://localhost:8080
```
